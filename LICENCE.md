## 🧩 About

**Factorio catalog Menu** is a curated list of Factorio open-source tools:

- **Overlays** — on-screen helpers, layout notes, production viewer, resource scanner
- **Quality-of-Life Helpers** — quick bar manager, inventory notes, overlay notes
- **Research Notes** — factory layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Gameplay Helpers
- Quick Bar Manager — customize and expand the quick bar
- Show Grid — visualize chunk and tile grids
- Production Viewer — monitor production and consumption rates
- Time Control — adjust game speed for study (0.1x to 10x)

### 🗺️ Map & Navigation
- Resource Scanner — locate resource patches on the map
- overlay Overlay — enhanced overlay coverage and map markers
- Blueprint Notes — organize and share blueprints
- Waypoint Manager — set and manage map waypoints

### 🏭 Factory Planning
- Layout Planner — design and test factory layouts
- Ratio Calculator — calculate optimal machine ratios
- Belt Balancer — visualize and balance belt flows
- Train Scheduler — plan train routes and schedules

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"factorio.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
